# 深挖链演练剧本 — 设计文档

> 面试备战产物。把《企业级 AI Harness 框架面试题 100 道》里的高频深挖链,做成可反复演练的剧本。
> 目标:面试官顺着一题往死里追时,你能逐环接住,而不是被"换个问法"问懵。

## 背景

`.interview/.project/企业级Harness架构与评测/100题.md` 是一份纯题库——有题、无答案、不挂用户真实经历。文末点明大厂考法:**不问完 100 题,而是挑一题连续深挖**,考的是能否形成闭环,不是背名词。

同目录已有 4 篇成体系"学习文"(完整长文、架构师视角SDD、五段一台机器、专业框架对照),风格统一:**大白话讲透 + 一个术语收口、每段只记第一句、源头分三档、评测=有纪律的赌**。本剧本是新的独立用途(演练而非讲解),沿用同风格、同命名习惯。

## 产物

单文件:`.interview/.project/企业级Harness架构与评测/02-深挖链演练剧本.md`

4 条链放一个文件,因共享同一套"读法说明",分文件会重复。

## 文件骨架

```
开篇:剧本怎么用(单人也能跑——遮住答法只看问法,先自己答再对)
      + 铁律提醒:大白话讲透 + 一个术语收口,别堆词;查无实据的数字一个不搬

链 1 · 状态/恢复/幂等      ← 高风险环挖真实代码
链 2 · Bad Case→评测      ← 有真实代码(app/evals)+ 文档打底
链 3 · 过度设计           ← 纯文档(素材来自简历工具包,非 OpsPilot)
链 4 · 高风险审批         ← 高风险环挖真实代码
```

## 每条链的内部结构

每条链 = 一个**起手题** + 若干**环**。每环五块:

| 块 | 内容 |
|---|---|
| 面试官怎么问 | 这一环的追问原话 |
| 你的标准答法 | 大白话答 + 挂证据(代码细节 or 文档框架) |
| 失分陷阱 | 这环答砸会怎样、面试官在等你掉哪个坑 |
| 收口术语 | 一个有出处的行业词锚定(如 Computational/Inferential、Blast Radius) |
| 变体问法 | 面试官换壳/继续追的几种问法,防"换个问法就懵" |

## 4 条链的起手题与环路

### 链 1 · 状态/恢复/幂等(文末样板链)
Harness 跟 Runtime 区别 → 状态存哪 → 进程挂了怎么恢复 → 工具重复执行怎么办 → 怎么保证幂等 → 怎么评测恢复机制 → 生产 Trace 怎么反哺 Eval

### 链 2 · Bad Case→评测
怎么证明 50% 提升 → Bad Case 怎么进评测集 → 几条 case 凭什么撑百万次判决 → gold set 怎么保证代表性 → inferential 维度谁判 → Trace 怎么反哺

### 链 3 · 过度设计
20Cmd/22Agent/75Skill 是不是过度设计 → 一个能力该做 Skill 还是写 Prompt → 该做 Tool 还是拆 Agent → 怎么证明不是堆

### 链 4 · 高风险审批
哪些动作必须 HITL → 审批的是计划/参数/Diff/还是最终动作 → 怎么防审批疲劳 → Policy 怎么独立于 Prompt 和模型

## 诚实边界(写答法的红线)

1. **链 2**:评测系统**真存在**(纠正:CLAUDE.md 称 Phase 8 未做已过时)。但要讲清它评的是**分类准确率这类 Computational 维度**(对标 gold dataset),别吹成"全自动 LLM 裁判判语义";被追"inferential 维度谁判"要接得住(目前更可能是人/离线)。
2. **链 3**:20Cmd/22Agent/75Skill 来自**简历的 AI 工具包,不是 OpsPilot**,答法别张冠李戴。
3. **全程**:大白话讲透 + 一个术语收口,不堆词;查无实据的数字一个不搬(对标"源头分三档")。
4. **OpsPilot 叙事**:按团队级落地讲,别照 demo 实现/踩坑复述。

## 非目标(YAGNI)

- 不覆盖 100 题全部,只做这 4 条链。
- 不做多 Agent 链、工具可靠性链(列为后续候选)。
- 不做现场口头演练(那是另一种用法,本产物只产出可读可背的剧本)。
- 不改任何 OpsPilot 代码,只读取核实。

## 成功标准

- 4 条链各有完整起手题 + 环路,每环五块齐全。
- 高风险环的"标准答法"挂的是上表核实过的真实代码细节,经得起"代码怎么实现的"追问。
- 诚实边界 4 条全部落实,无虚构数字、无张冠李戴。
- 风格与现有 4 篇学习文一致。
